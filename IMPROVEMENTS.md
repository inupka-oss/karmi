## 🔧 Требуемые изменения в базе данных (Supabase)

### 1. Таблица достижений
```sql
CREATE TABLE user_achievements (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  achievement_id TEXT,
  unlocked_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 2. Таблица челленджей
```sql
CREATE TABLE user_challenges (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  challenge_id TEXT,
  progress INT DEFAULT 0,
  completed BOOLEAN DEFAULT FALSE,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 3. Таблица коллекционных карточек
```sql
CREATE TABLE collection_cards (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  anime_id UUID REFERENCES anime(id),
  rarity TEXT CHECK (rarity IN ('common', 'rare', 'epic', 'legendary')),
  obtained_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 4. Таблица реакций на комментарии
```sql
CREATE TABLE comment_reactions (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  comment_id UUID REFERENCES comments(id),
  type TEXT CHECK (type IN ('like', 'dislike')),
  UNIQUE(user_id, comment_id)
);
```

### 5. Обновление таблицы комментариев
```sql
ALTER TABLE comments ADD COLUMN parent_id UUID REFERENCES comments(id);
ALTER TABLE comments ADD COLUMN likes INT DEFAULT 0;
ALTER TABLE comments ADD COLUMN dislikes INT DEFAULT 0;
ALTER TABLE comments ADD COLUMN is_deleted BOOLEAN DEFAULT FALSE;
ALTER TABLE comments ADD COLUMN reports_count INT DEFAULT 0;
```

### 6. Обновление таблицы user_profiles
```sql
ALTER TABLE user_profiles ADD COLUMN stats JSONB;
ALTER TABLE user_profiles ADD COLUMN achievements TEXT[];
ALTER TABLE user_profiles ADD COLUMN badges TEXT[];
ALTER TABLE user_profiles ADD COLUMN avatar TEXT;
ALTER TABLE user_profiles ADD COLUMN bio TEXT;
ALTER TABLE user_profiles ADD COLUMN last_active TIMESTAMPTZ;
ALTER TABLE user_profiles ADD COLUMN is_banned BOOLEAN DEFAULT FALSE;
```
